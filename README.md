# Mconnectz for Android

Download the latest Mconnectz app for Android (7.0 or newer):

**[Download mconnectz.apk](https://github.com/casamart/mconnectz-android/releases/latest/download/mconnectz.apk)**

Open the file on your phone to install. If Android asks, allow installs from
your browser or file manager. Installing a new version over an old one keeps
your account and savings.

This repository only hosts the app's releases; it contains no source code.
